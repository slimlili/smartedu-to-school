本课目标学习目标

1.通过类比电场强度引入电势的概念，理解电势是从能的角度描述电场的物理量。

2.知道电势的相对性，了解常见的电势零点的规定方法。

3.会计算电场中某点电势的大小，能判断电场中两点电势的高低。

学习任务一【学习任务一】

做一做：在电场强度为E 的匀强电场中，沿电场线方向

有A、B、C 三点， A、B 与C 的距离分别为l1和l2。若规定电荷在C 点的电势能为0。计算电荷+q 与电荷+nq 在A、B两点的电势能以及电势能跟电荷量的比值。分析你的计算结果，看看你能发现什么规律？

A、B、C 沿电场线同向排列，C 为电势能零点，A 距 C 为 l1、B 距 C 为 l2（l1>l2，A 更靠上游）。
电荷 +q：EpA=qEl1，EpB=qEl2，EpC=0；电荷 +nq：EpA=nqEl1，EpB=nqEl2。
发现：各点 Ep/q 与试探电荷的电荷量 q 无关，只与该点位置有关——这正是电势概念的由来。
学习任务二【学习任务二】

做一做：在正点电荷形成的电场中，将电荷量为+q 的试探电荷1 从A 点移动到无限远处，静电力做功为W。若规定电荷在无

限远处的电势能为0。（1）计算试探电荷1 在A 点的电势能与电荷量的比值；（2）若将电荷量为+nq 的试探电荷2 放在A 点，计算其电势能与电荷量的比值。

(1) 试探电荷1（电荷量 q）从 A 移到无限远静电力做功 W，取无限远 Ep=0，由 W=EpA−0，得 EpA=W，故 EpA/q=W/q。
(2) 试探电荷2（电荷量 nq）在 A 点的电势能为 EpA′=nq·(W/q)=nW，故 EpA′/(nq)=W/q。
结论：同一点 Ep/q 恒定，与放入电荷的电荷量无关，只由电场决定 → 定义为电势 φ=Ep/q。
学习任务三【学习任务三】

做一做：匀强电场的电场强度为E=3000N/C，A、B 与C 的距离l1 和l2 分别为0.1m 和0.04m。（1）以C 点为零电势点，求A、B 两点的电势；（2）以B 点为零电势点，求A、C 两点的电势。

场强 E=3000 N/C，A 距 C 0.1 m，B 距 C 0.04 m（沿电场线，C—B—A）。
(1) 以 C 为零电势点：
φA = E·AC = 3000×0.1 = 300 V
φB = E·BC = 3000×0.04 = 120 V
(2) 以 B 为零电势点：AB=0.1−0.04=0.06 m
φA = E·AB = 3000×0.06 = 180 V
φC = −E·BC = −3000×0.04 = −120 V
说明：电势数值随零点选取而变，但两点间电势差不变（如 φA−φB 恒为 180 V）。

学习任务五【学习任务五】

做一做：一个电场中有 A、B 两点，电荷量q1 为1×10-9C 的试探电荷放在电场中的A 点，具有－2×10-8 J 的电势能；q2 为－2×10-9 C 的试探电荷放在电场中的B 点，具有6×10-8 J 的电势能。现把q3 为－4×10-9 C 的试探电荷由A 点移到B 点，求静电力所做的功。

由 φ=Ep/q：
φA = (−2×10⁻⁸)/(1×10⁻⁹) = −20 V
φB = (6×10⁻⁸)/(−2×10⁻⁹) = −30 V
将 q3=−4×10⁻⁹ C 由 A 移到 B，静电力做功
W = q3(φA−φB) = (−4×10⁻⁹)×[−20−(−30)] = (−4×10⁻⁹)×10 = −4×10⁻⁸ J
（q3 为负电荷，从较高电势 A 移向较低电势 B，静电力做负功。）
学习任务六【学习任务六】

根据你的理解，总结本节课的内容。

参考要点：① 电势 φ=Ep/q，是标量，与试探电荷无关，只由电场与位置决定；② 沿电场线方向电势降低；③ 电势能 Ep=qφ，正负随电荷而定；④ 电势与零势点选取有关，电势差与零点选取无关；⑤ 用 Ep/q 定义电势，体现“用能量刻画电场性质”的思想。
