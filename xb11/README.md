## 为什么不用 pandoc / docx2md 直出

这批 docx 的公式有三种形态，其中两种会被常规工具**静默丢弃或解错**：

1. **Word EQ 域**（`eq \f(U,L)`）—— pandoc 直接丢掉整段，
   解析结果会变成 `E＝≈2.2×10⁻³`（中间公式没了）。见 `omml.py: eq_to_latex`。
2. **Word 原生公式 OMML**（`m:oMath`）—— 用 `omml.py` 手写渲染。
3. **MathType OLE**（`w:object` + `oleObject`）—— 用 `docx2md/vendor/mtef_pkg`
   无损转 LaTeX。**注意**：个别对象会解出「看似合理但实则错误」的公式
   （如 11.2 把字母 `C` 解成 `C-y+1-m=0`），这类错误不会报错，只能靠人工比对，
   因此每次构建都会生成 `公式校对清单.md`；确认有误的写进 `docxparse.MTEF_FIXES`。

另外 MTEF 吐出的是老式 LaTeX（`$ 4{ \rm{ m } }{ \rm{ m } } ^ { 2 }  $`），
`latex2html.normalize` 负责清洗成 `4mm²`。

## 整章总册的节标题

`merge.py` 不在节与节之间插整页分隔页，而是在每讲起始处放一条**大字标题条**
（`第十一章 电路及其应用 · 第 N 讲` + 讲名），并**盖掉该页原有的重复页眉**
（总册里连续多页印同一页眉很累赘）：

- 上一讲内容**已过半页** → 另起一页再放标题条；
- 未过半页 → 直接接在后面，不浪费纸。

## 几条关键经验

- **公式一律转 HTML（`<sub>/<sup>/<i>` + CSS 分数），不用 MathJax/KaTeX**：
  Chrome headless 打印不嵌 webfont，KaTeX 会乱码；CSS 方案离线自包含、打印一致。
- **图片内联成 base64**（`postprocess.inline_images`），单文件自包含，无路径依赖。
- **图片式小标题还原成文字**：原教辅的「易错辨析」「例题」是 `INCLUDEPICTURE`
  引入的图片，且套了 9 层嵌套域。按文件名区分——中文名是徽章（还原为文字），
  编号（`11-1`）才是真插图。见 `docxparse._img_ok`。
- **题号分组**：11.4 一讲里有两套 1~6 题（《一》《二》），内部用 `qgroup`
  把题号变唯一以匹配答案，显示仍用原题号。
- **改到共用文件时加开关**：`render_ws.PRESERVE_PARAS`（默认 False，平台版不受影响）
  与 `build_deck_html.build_slides(task_key=…)`（默认 None）。

## 又一个「静默错误」

11.2 第 2 题的**选项被做成了内嵌 Word 文档对象**（`OLEObject ProgID=Word.Document`），
预览图是 EMF——浏览器既渲染不出图，选项文字也全丢。现在 `docxparse._embed_doc_text`
会把内嵌包（OLE 的 `package` 流）解出来读正文，其中的 `eq \f(I2,2)` 域也转成了公式。

顺带修掉 `_cut_marker` 的一个隐患：它原先用 `^(?:<[^>]+>|\s)*` 跳过一切前导标签，
把排在题号**之前**的题图（`<img>`）整个吃掉了（11.2 第 1、3 题丢图）。现在只跳空标签。

## 版式细化（2026-09-13 第二轮）

- **章/节标题**：章标题 24pt 居中；节标题分三行——章名 / `第N节 节名` / 课时（若有），
  逐行居中、字号 15/22/15pt，比正文明显大一号，且整块不跨页。
- **选项排版** `render_ws.OPTS_LINES`（默认 False）：按长短自动 1 / 2 / 4 行。
  1、2 行时行内 `space-between` 等间距、两边对齐；4 行时每项独占一行。
- **作答区与配图并排**（仅学生版）：题干通栏，下一行「左虚线作答区 + 右配图」，
  图限高 112px。原来图在 `.q` 里整块占满宽度，把作答区挤到看不到。

### 这一轮踩的坑

- **选项标记不能把「、」算进去**：题干「得到了图中 $ A $、$ B $、C、$ D $ 四个点」
  的顿号会被当成选项分隔，把题干切碎。实测源文件里 60 处选项全用 `.`/`．`，
  没有一处用 `、`，所以直接不认 `、`。
- **`Ω` 在 Python 里 `isalnum()` 为真**：用它当「前一字符是字母数字就跳过」的判据，
  会把 `…0.85ΩB．…` 里的 `B．` 误挡掉。这个保护只该针对 ASCII。
- **flex 布局要按标签配对定位**：`html.find('</div></div>')` 会被嵌套的
  `<div class="qbody">` 提前截断，把 `.sidefig` 塞到 `qwrap` 外面，整块排版崩掉。
- **带图/带选项的题原先不包 `qwrap`**，导致图片重排对它们完全失效。

## 配图排版（2026-09-13 第四轮）

学习任务/课堂探究的配图统一走两条规则（`postprocess.reflow_task_figs`）：

- 区块内**有作答区** → 图配到作答区右侧，排成「左虚线 + 右图」一行；
- 区块内**没有作答区**（课堂探究、学习目标）→ 图**就地浮动**在所属小问右侧。
  图原本就排在它所属的那一问之前，原地浮动能保持「图跟着问题走」。

### 这一轮踩的坑

- **浮动泄漏**：`_reflow_section` 拿到的是不含收尾 `</div>` 的片段，配位逻辑失败时
  `block[:0] + fig + block[0:]` 会把图插到区块**外面**，浮动于是盖住后面几节，
  把正文挤成窄条。现在两种情形都保证图留在区块内。
- **`_ANSSPACE` 用 `.*?</div>` 匹配**：会截在作答区**内部**，把 `.taskfig` 塞进
  `.ansspace` 里。改用标签配对 `_find_ansspaces`。
- **两端对齐 + 行内公式 = 散字**：`p{text-align:justify}` 配合 nowrap 的公式块，
  浏览器为撑满行宽会把两侧汉字拉开（判断正误第 3 条）。已加 `p:has(.m){text-align:left}`。

## 配图归属与题号（2026-09-13 第五轮）

- **章/节字号**：章 30pt > 节 19pt。之前"看着反"是因为节标题里**又印了一行
  13pt 的章名**，紧挨在 30pt 章标题下面。现在节标题只写「第N节 节名」（+课时）。
- **配图归属统一为一条规则**：每张图挂到「它后面的第一个段落」右侧。

  插入点必须先全部登记再统一插入——边插边改会让偏移量失效，两张图互相穿插。
- **思考题留作答空间**：`_THINK` 匹配「思考N：／想一想／做一做…」，

- **漏编号的题干自动补号**：源稿里 11.4 第二个「自我测评」第 1 题没写题号，
  按"本组内已建题数 + 1"补。`cur_max_no()` 只能看**本组**，否则会被上一组的 6 带偏。

## 修复：学生版印出课后练习答案（2026-09-13）

11.3a 学生版末尾出现了 `1 18.4  2．0.900 …` 这样的答案串。
根因是处理**顺序**：`【课后练习答案】` 同时匹配 `ANS_HEAD_RE` 和 `H_TITLES`，
而答案分支排在标题分支**之前**，于是它被当作「答案标题」消费掉了——
只设了 `ans_mode` 却没设 `ctx='answer'`，紧随其后的答案行就被题号规则
抓成了题目（Q1、Q3…），学生版自然就把答案印了出来。

修法：答案标题分支一并把 `ctx` 切到 `'answer'`。

排查同类问题的方法——学生版里搜形如 `N．数值` 的答案行特征：

    python3 -c "
    import fitz,re,glob,os
    for f in sorted(glob.glob('pdf/*_学生版.pdf')):
        t=''.join(fitz.open(f)[i].get_text() for i in range(fitz.open(f).page_count))
        print(os.path.basename(f), len(re.findall(r'\d+[．.]\s*\d+\.\d+', t)))
    "
